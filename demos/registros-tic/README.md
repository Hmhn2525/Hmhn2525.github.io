# Registros TIC · ejemplo del portafolio

Este paquete contiene una demostración independiente con datos ficticios.

- Abrir la demo: demo/index.html
- Ver verificaciones: docs/verification.md
- Reproducir el verificador desde esta carpeta:

    python examples/verify.py

Los resultados y cambios de la demo no prueban la interfaz, los servicios o la persistencia operativa. El origen y alcance están en la página del caso.
