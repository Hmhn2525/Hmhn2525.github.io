Inventario Físico

Conciliación ficticia de cinco líneas: cuatro contadas, una pendiente excluida y diferencia neta de -2.5.

Abrir demostraciónReproducir ejemplo y ver comandoVer comprobaciones

Problema operativo

Digitalizar auditorías de almacén distinguiendo de forma estricta una partida pendiente de un conteo confirmado de cero.

Solución técnica

Plataforma web (Subir reporte → Contar → Resumen), control de versiones por partida y conciliación con diferencias exactas.

Tecnologías observadas

  • React
  • TypeScript
  • ASP.NET Core
  • PostgreSQL

Ejemplo reproducible

Entrada: Cinco líneas: cuatro conteos (incluido cero) y una línea sin contar.

Resultado: Diferencia neta de -2.5; la línea pendiente queda fuera del cálculo.

Decisión técnica: Usar Decimal conserva fracciones exactas y evita convertir una ausencia en cero.

Evidencia verificable

El verificador comprueba coincidencia, faltantes, cero confirmado, sobrante y pendiente con aritmética decimal exacta.
